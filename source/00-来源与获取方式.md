## 3. 抓取方法（重要）

两处页面均为 **SPA**（Vue + Aegis SDK），直接 `curl` 或普通抓取工具只能拿到空壳（正文由 JS 渲染），且其后端数据接口路径无法从 bundle 中稳定还原。

**可行方法**：用系统 Chrome 无头模式渲染后取 DOM：

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
PROF=$(mktemp -d)
"$CHROME" --headless=new --disable-gpu --no-sandbox \
  --user-data-dir="$PROF" --virtual-time-budget=20000 \
  --dump-dom "https://privacy.qq.com/document/preview/771d9a58551449e9a7e7445ebfe04966" \
  > /tmp/dom_privacy.html 2>/dev/null
```

随后剥离 `<script>`/`<style>` 与标签、反转义，即得正文纯文本。
