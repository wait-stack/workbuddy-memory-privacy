## 核心结论（一句话版）

WorkBuddy 的记忆功能**基于对话内容由大模型在服务端自动提取**"具有参考价值的个人信息"并**定期更新**，后续对话中作为**背景信息与用户输入一并注入**；记忆数据**存储于中国境内**；用户可在客户端**查看/增删改**并**关闭提取**，但条款仅承诺关闭后"不再提取"，未承诺删除已提取内容。

## 关键条款索引

- **§3.7.1–3.7.5** 记忆功能（定义 / 产生 / 注入 / 管理 / 关闭）
- **§3.6.3** 智能对话数据流（记忆的上游原料：输入、输出、对话主题）
- **§3.6.2** 日志数据（输入输出时间戳、设备标识、浏览器指纹）
- **§3.13.3** 企业账号场景下最终用户的使用行为
- **§7.1–7.2** 存储地点与期限（境内，不跨境）
- **§9.1 / §9.5** 个人信息权利与账号注销
